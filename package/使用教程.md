# Atom 群文件工作台 使用教程

适用版本：Atom 0.5.0（内置工作台 0.8.5），Windows x64 DSH 桌面版。

本版帮助业务员按群核对附件：先按分钟读取文件清单和系统建议目录，人工勾选、补选或调整目录，经过二次确认后再保存本机已有的附件。读取预览不复制、不迁入归档文件。归档本身不读取正文；识别单据、导出订单 Excel 是单独的建单入口，见“按归档目录建单”。插件也不从服务器下载本地缺失的文件。

## 安装和升级

安装 `dsh-atom-0.5.0.tgz` 后启用并重启 DSH，左侧入口为“Atom 群文件工作台”，插件卡片为“Atom”。通过中转站分发时，上传到易链市场条目的“发布新版本”，不是任务插件页面。

0.8.5 让子压缩包解压到以它命名的子目录：开启「同时处理子压缩包」递归解压，或手动点已落地子压缩包的「解压」时，子包内容放进以它名字（去扩展名）命名的子目录（如 `内层.zip` → `内层\`），逐层递归形成 `主目录\子包名\…`，不再与主压缩包的直接内容混在一起；主压缩包内容仍拍平到它所在目录。详见“保存目录和结果”。

0.8.4 把「解压」改为直接解压：点文件列表「状态」列或目录视图文件卡片上的「解压」不再弹框，直接把包内文件拍平解压到压缩包所在目录，整包保留；「群与保存目录」新增「压缩包处理」，可开启保存后自动解压与逐层处理子压缩包（最多 8 层）。解压结果用悬浮提示展示，解压出的文件在目录视图里直接可见，详见“保存目录和结果”。

0.8 起，界面统一使用「目录」口径：群卡片可「设置默认目录」「为选中文件创建目录」，单行归档入口为「保存到已存在目录」，查看已保存文件为「按目录查看已保存文件」。保存结果会保留保存前各群的保存状态筛选与展开状态；删除归档副本或单行归档后，分组标签的已选计数和全选范围立即刷新。单行保存成功后，该行按已保存显示；若保存前已勾选，成功后自动取消勾选。

0.7.4 调整宿主 SDK 的安装声明，适合全新电脑直接安装。生产安装链路的公共修复为易链市场 0.1.22，由管理员统一分发或纳入桌面安装包；员工无需逐台更改 profile、手工下载 canvas 或清空缓存。安装失败时按实际错误处理，不能把“依赖文件已下载”当作已启用。

管理员的分发顺序：先在桌面发行物中替换内置易链市场为 0.1.22，或通过既有软件分发机制升级该组件；完全重启使新安装器运行后，在生产市场发布企微插件 0.8.5。仅上传插件包不能替换员工桌面内的旧市场安装代码。如果旧市场的升级本身也被同一安装故障阻断，应使用包含修复的新桌面版本统一分发，不要求业务员手改配置。正式发布后再从生产目录做一次新电脑安装和卸载重装验收。

0.7.3 在成功保存配置后同时清空下方按群列出的文件预览、统计、页码、勾选和未确认的目录调整；切换页面、刷新及重启不恢复旧结果，重新读取后显示新清单。群配置和已归档的实体文件保留。0.7.2 的设置框自动收起和原生日期时间输入继续保留。

更正 0.6.1 曾附带的说明：不要求先升级易链市场 0.1.21。此前旧版归档包已在原版市场 0.1.19 下完成正常安装、卸载和重装对照，不能据另一条安装器异常路径认定必须升级市场。本版本只发布归档插件包。若实际机器仍显示“未入 bundles”，应核对该机的启用记录及安装日志，保留 `.eline` 配置和已有归档文件。

0.7.0 将原先读取后直接保存的行为改为“读取预览 → 检查分配和选择 → 确认保存”。旧版结果仍可查看，需要重新读取才能生成可确认的预览；原有群配置与保存目录保留。

默认插件配置和上次文件清单保存在宿主应用数据根目录下的 `plugin-data/wecom-fws`：易联桌面为 `C:\Users\你的用户名\.eline\plugin-data\wecom-fws`，SparkSeed 桌面为 `C:\Users\你的用户名\.sparkseed\plugin-data\wecom-fws`。首次启动新版会在新目录没有数据时，自动导入原 `.eline`、`.dsh` 目录下 `plugin-data/wecom-files` 中的配置和结果，无需重新选择群；旧目录中的文件保留作备份。新目录已有配置或结果时，优先使用新数据。

这里的“插件数据”是配置和文件清单。实际保存的群附件仍在你填写的“保存目录”，不会因此被搬到 `.eline`。若管理员设置过独立的插件状态目录，则继续使用管理员指定的位置。导入报错时请保留旧数据，检查新目录权限及旧配置是否完整后重试。

保持企微登录，与 DSH 使用同一 Windows 用户和权限级别。附件需先由企微完成下载，保存目录建议使用本机 NTFS 磁盘。

## 第一次配置

1. 展开“群与保存目录”，检查企微数据根目录。此目录应直接包含数字账号子目录，例如“文档\WXWork”。
2. 点击“读取账号与组织”。下拉框优先显示“组织名称 · 本人姓名”，不再只显示数字 ID。
3. 如果有名称相同的账号，目录尾号可作为辅助信息。历史账号资料可能不可读，会明确标注；确认后可填写“账号显示名称”。该名称只用于本插件。
4. 在“群名称关键词”输入部分群名，例如“智能识别项目”，点击“查找群”，或按回车。
5. 查看每条结果的最近消息、“群附件记录”、“群成员人数”和附件示例。带“近期会话，可优先核对”的记录通常更适合近期工作；“较早会话”可能保留历史资料。群附件记录是本机可读的该群全部历史附件记录数量，不是所选日期的单量；成员人数也以本机可读信息为准。
6. 点击“添加此群”，可以继续查找和添加其他群。不会仅凭同名自动合并不同 ID 的会话。
7. 同名的近期和历史记录都需要时，可以全部添加。第二条默认建议使用“群名（历史资料）”等中文目录名，也可以自行修改“保存子目录名”。不同会话的子目录名必须不同，不需要删掉其中一个群。
8. 选择保存根目录，在下方设置“分组目录索引存留时间”（默认 7，可填 1～365，输入框下方提示「仅保存近 x 天的分组目录索引」）：每次读取前会丢弃超过该天数的“已保存”记录，旧记录不再标注已保存；填错非整数或超出范围时保存按钮不可点。保留天数和默认筛选都只影响之后的读取：点击“保存配置”会清空当前预览，需要重新读取生成清单，届时按新天数丢弃超期的已保存记录。下方还有“默认筛选”三段选择（未保存／已保存／全部）：读取后各群卡片默认按该状态显示，例如选“未保存”时只显示尚未保存的文件，仍可在群卡片上随时切换；该默认值同样只影响之后的读取。再下方是“压缩包处理”两项开关：“保存后自动解压”（默认关，开启后批量保存、单行保存与“保存到已存在目录”完成后自动解压本次保存的 zip/rar）与“同时处理子压缩包”（默认关，开启后逐层递归解压落地的压缩包，最多 8 层）；解压失败不影响保存结果，详见“保存目录和结果”。点击“保存配置”。成功后设置框自动收起，群名搜索和下方全部文件预览清空，未确认的勾选、页码和目录草稿也清空；即使配置没改，点击保存也会清空。已选群和已归档文件保留。切换页面或重启不会恢复已清空的清单；选择范围后重新点击“读取全部文件”或“读取提单文件”生成新预览。需要修改配置时点击“群与保存目录”标题展开。保存失败时保持展开、搜索和原文件预览，修正后重试。更换保存根目录时「已保存」索引会整体清空，旧根目录里已归档的文件在新根下按未保存处理，需要时重新勾选保存；同一目录仅换写法（尾部分隔符、盘符大小写）不算更换，不会清空。

升级前保存过两个同名记录的，打开配置后直接修改其中一个“保存子目录名”并保存。没有区分目录前，更新按钮仍会阻止混存。

## 目录怎样填写

“保存目录”填写完整路径，推荐点击“选择目录”。正常的 `D:\客户资料` 或 `D:/客户资料` 都可以，完整的 `\\服务器\共享\客户资料` 也符合路径语法，但实际保存仍要求目标文件系统支持硬链接。路径中的分隔符和盘符冒号是正常结构。

“保存子目录名”只填写一个文件夹名称，例如 `智能识别项目开发群`、`客户群（历史资料）`，不要填写整条路径。

以下内容会被阻止保存，界面会明确提示原因：

- 任一目录名含 `\ / : * ? " < > |` 或控制字符。“保存目录”中作为路径结构的分隔符、盘符冒号除外。
- 目录名为空、以空格或句点结尾，或使用 `CON`、`NUL`、`COM1` 等 Windows 保留名称。
- 路径中使用 `.` 或 `..`，以及保存子目录名超过 180 字符。
- 盘符不存在、已有路径实际是文件而不是文件夹，或保存位置位于企微源目录、插件状态目录内部。

例如 `D:\客户?资料`、`客户/一组`（子目录名）均不允许；`D:\客户资料\一组`（完整保存目录）允许。尚未创建的新目录可以填写，在确认保存文件时创建。升级后若旧配置含非法目录，工作台仍可打开，修正并点击“保存配置”后再读取预览。

## 每天怎样操作

1. 设置“开始时间”和“结束时间”，精确到分钟，按北京时间解释。可直接编辑输入框中的年、月、日、时、分，也可点击框内日历图标使用原生日期弹窗；年份选择在该弹窗内完成，不再显示独立年份按钮。弹窗采用浅色配色，具体内部布局由桌面浏览器绘制。默认今天 00:00～23:59。“今天”“昨天”只调整范围，不发起读取或保存。
2. 点击“读取全部文件”或“读取提单文件”。两个入口都会读取已保存群在范围内的全部附件记录，只生成预览、建议勾选和建议目录。完成后结果区顶部显示一行查询结果提示（结果状态 · 操作 · 本次读取方式），每群的文件数量看群卡片标题的“全部文件 · 可保存 · 已选文件”，已选总数在点击“保存”后的确认框中核对；保存结果中的「可保存」不包含本次已保存和已存在的行。若有附件没能列入清单，这一行下方会给出警告，写明未列入清单的附件数量（在消息记录中找不到对应时间）或未找到的群名。
3. 每个群单独显示，群内默认按消息时间从晚到早排列，可点击表头「时间」后的上下箭头切换为从早到晚。每个群卡片的文件表格、分页、空结果提示与分栏视图共用固定高度的内容区（657px），条目为空、不足一页、翻页或切换视图时群卡片高度不变，内容超出时在内容区内滚动。每个群卡片的操作区分为三行，前两行左对齐：第一行是查询输入框、「查询」按钮和「未保存／已保存／全部」三段筛选，筛选生效时匹配数量显示在筛选控件右侧；第二行是「设置默认目录」「为选中文件创建目录」「保存」，最右侧另有一个右对齐的「按目录查看已保存文件」；第三行是「只查看未收入目录文件」按钮与分组标签（按钮固定在分组标签之前）。在查询框输入关键词后按回车或点「查询」执行过滤（不区分大小写，多个关键词用空格分隔时须全部命中；关键词会匹配文件名、表格中显示的文件保存目录，包括分组、默认目录和逐文件修改，以及上次保存路径；清空输入再点查询恢复完整列表）。选「未保存」时读取、显示、匹配数量和翻页都只包含尚未保存的文件，选「已保存」时只包含索引中可复用的文件，选「全部」则不过滤；切换时从第 1 页重新加载。保存状态、查询和分组筛选可以叠加，匹配数量与翻页范围跟随叠加后的结果。预览中的已保存指有可复用索引或归档回查记录的文件；保存结果中的已保存指本次新增、校验通过（已存在）或此前已保存并保留标记的文件，其余记录归入未保存。展开需要核对的群，检查文件名、消息时间、命中的疑似提单号、文件保存目录和状态（表头为「状态」）。点「按目录查看已保存文件」可把文件列表区域切换为左右分栏的目录视图（按钮变为「返回文件列表」）：左侧列表上方有「目录名／文件数量（合计）」标头，与右侧文件卡片上端对齐，只显示每个目录的最后一级名称（完整路径显示在右侧卡片，悬停左侧项也可查看），目录较多时每页 10 条；单击条目查看该目录，双击选中整段组名文字便于复制；目录分页固定在列表最下方并保持单排（始终显示，只有 1 页时按钮禁用），分页按钮与文件列表使用同一标准高度，左右两侧分页底端对齐；点击某个目录后，右侧卡片顶部先显示复制文件目录按钮、再显示完整路径，二者垂直居中对齐，下方是该目录当页的文件（文件名靠左，消息时间右对齐并紧邻操作按钮，悬停可看完整路径），每条文件名右侧有「重命名」「删除」按钮，zip/rar 压缩包另有「解压」按钮；解压出的文件在文件名旁标注「来自 xxx.zip/rar」：重命名只修改归档副本的文件名，目标名称已存在时会拒绝并提示；删除归档副本后，该文件在预览中恢复为未保存、在保存结果中恢复为未选择，可重新勾选或重新归档，企微中的原文件不受影响。每页 10 条，分页始终显示在卡片底部。左右两栏卡片固定为同一高度（641px，与内容区保持 16px 间距），列表在卡片内伸展并可滚动，条目不足、为空、加载中或没有选中目录时卡片高度都不变。查看期间查询框和「查询」仍可用，关键词变化会重新载入分组视图；「未保存／已保存／全部」筛选、「设置默认目录」「为选中文件创建目录」「保存」以及分组标签上的勾选与移除都置灰禁用，返回文件列表后恢复。未保存文件不在该视图中，它始终查看已保存文件，不受「未保存／已保存／全部」筛选影响；保存文件较多时只统计前 10000 份。每群每页 10 条，可独立翻页、折叠，并可在分页栏输入页码跳转；翻页范围跟随搜索匹配结果。切换查询、保存状态筛选、分组筛选、排序或翻页时，列表在新结果返回前保留当前页内容，并保持面板滚动位置，避免页面跳动。
4. 勾选或取消文件列表「勾选」列表头的全选复选框：范围是当前筛选结果，即叠加保存状态、查询和分组筛选后的全部页文件；没有这些筛选时就是本群全部可保存文件。勾选即选中该范围，取消勾选即清空该范围；范围内只有部分文件被选中时复选框显示半选状态，此时再点击会补全为全选，范围外的勾选保留。之后仍可逐行补选或取消；鼠标悬停可查看当前范围和“作用于全部页”的说明。当前范围超过 10000 份可保存文件时只处理前 10000 份，提示会说明。分组标签左侧还有整组复选框：勾选即选中该组全部可保存文件（跨页、忽略当前筛选，已保存过的文件不计入），部分选中时点击补全为全选，取消即清空组内选择；标签显示「已选 x / 共 n」，「只查看未收入目录文件」筛选下不能整组选择。
5. 检查系统分配的文件夹，需要时逐份修改“文件保存目录”，或用群卡片上的两个按钮统一调整：点「设置默认目录」输入目录名，本群当前已选文件以及之后新勾选的文件都会使用该目录；群名旁的「文件将会存放在」按“群目录\文件接收日期\文件名\文件”展示计划位置，配置默认目录后中间一段改为该文件夹名，点击分组标签筛选时改为分组名，点“×”可取消默认目录；点「为选中文件创建目录」，弹框中的目录名默认取本群第一个选中文件的文件名（不含扩展名），确认后这些选中文件（含其他页）保留勾选并统一使用同名保存子目录，分组以标签形式显示在卡片上并标出文件数和「已选 x / 共 n」，点标签上的“×”只移除分组与对应目录预设，不取消文件勾选。分组只是命名的勾选与目录预设，不是第二条保存通道；取消勾选某个成员后，该行保留文件夹显示并标注「已分组，未勾选（不会保存）」。之后点「只查看未收入目录文件」继续勾选其他文件并创建新分组时，只会收集新勾选且尚未归组的文件，不会把已有分组成员再次带入。保存目录优先级为逐文件修改 > 分组 > 默认目录 > 系统分配目录；目录名须符合目录名规则，分组本群内不能重名。本群没有选中文件时创建分组按钮禁用。点击分组标签可只看该组文件，再次点击取消；点「只查看未收入目录文件」可反向筛选尚未归组的文件，筛选可与查询、保存状态叠加。这里只修改本次预览草稿。保存过的文件会被记住：每次保存时实际使用的「文件保存目录」（默认目录或自定义分组目录）会随保存路径一起记下；重新读取时，上次已保存且文件仍在原路径的附件标注「已保存」，其「文件保存目录」恢复为上次实际保存的目录，悬停可看上次保存路径，默认不勾选、不计入本次保存数量；需要重新校验或另存时手动勾选即可。状态里还没有记录的旧存档，首次读取时会在同一群同一天的归档目录中按同名同大小回查唯一副本并补记；文件被移动或删除后按未保存处理。已保存记录默认保留 7 天，可在「群与保存目录」中调整，超过保留期后不再标注已保存，也不再回查补记。本群已经有归档目录时，还可以直接在文件列表的「保存到已存在目录」列选择一个已保存目录：选中后会立即按该目录名归档这一份文件并更新已保存索引，保存成功后该行按已保存显示，若保存前已勾选则自动取消勾选；本次预览通过「为选中文件创建目录」创建的分组不会出现在这里，这些分组请使用「保存」按钮归档；它只处理这一行，不会替用户勾选或提交其他文件，也不等同于点击「保存」后的整批确认。在命名分组筛选视图中，如果保存状态筛选为「未保存」，单行保存成功后会将该群视图自动切换到「全部」，让刚归档的条目继续可见；分组归属和归档结果都不变。预览中标注「已保存」的行仍可手动勾选，用于重新校验或另存；「保存到已存在目录」下拉对这类行保持禁用。保存结果中的已保存行仍不可勾选。下拉只列出本群已归档目录的最后一级名称，刷新、保存或重新读取后仍可直接选择历史目录。
6. 检查无误后保存：点某个群卡片第二行的「保存」或右下角悬浮的胶囊形「保存」，都会打开保存范围确认框。卡片入口默认只勾选本群；悬浮入口默认勾选各群中已配置文件夹且有选中文件的群。可在确认框中逐群勾选或取消本次要保存的群，未勾选的群不会提交，其文件勾选状态保留到下次确认。没有指定文件夹的文件所在群默认不勾选；主动勾选后，该群卡片内会出现确认勾选项，必须勾选“我确认让这些文件按文件名各自创建子目录（N 份）”，否则“确认并保存”不可点；取消勾选该群会同时清除这条确认。确认框还会显示所选数量、读取时间范围、保存根目录，以及每个勾选群的目录去向。核对后点击“确认并保存”。群内单独保存完成后，其他来源群的卡片和文件仍保留在结果中（标为「未选择，仅列出」），可直接补选后继续保存，不必重新读取；先前已保存、本次未重新勾选的文件仍显示「已保存」并保留上次保存目录（悬停可看完整路径），不会变成「未选择」。群卡片或右下角「保存」完成后，界面会浮出“保存完成”提示（群内保存时带群名），列出新增、已存在和未保存数量（未保存聚合所有失败与待处理状态），8 秒后自动收起，也可点“×”关闭；结果行同时显示新增、已存在和未保存数量。点击“返回检查”则继续调整，不执行保存。
7. 保存完成后检查每群结果。本地原件缺失时，先在企微完成下载，再重新勾选并再次确认（重试只提交这次重新勾选的文件，不会带入上次已保存但未勾选的文件）；同内容副本会复用。图片、视频附件只要企微已下载到本机（分别在账号目录的图片、视频缓存区），也会被找到并归档，不需要手工另存。

时间范围按客户最初发送附件的消息时间，不按今天下载到电脑的时间。开始和结束分钟都包含：例如结束时间为 11:00，包含 11:00:00～11:00:59 的消息；实际读取不超过点击读取时的截止时刻。开始晚于结束、开始晚于当前截止时刻或非法时间会被拒绝。较早记录与当前记录可能需要都添加才能检查相应历史。

“读取全部文件”默认勾选可保存且本次尚未保存的全部附件；“读取提单文件”默认勾选文件名命中、且格式允许的未保存附件。最终只保存人工确认时选中的记录。来源冲突、缺少可靠校验信息等记录仍显示原因，不能勾选。预览列出的数量是附件数量，不是业务订单数量。

修改群配置、保存根目录并保存后，必须重新读取文件生成预览；改变时间范围后也需重新读取。这样确认框的范围和目标目录才与本次计划一致。读取完成以后新收到的消息不自动加入原预览，需要再次读取。

## 翻页和切换会话

某个群翻到第 3 页后，可以切换到其他群或点击左侧会话处理其他工作，再点击“Atom 群文件工作台”回来。只要还是同一次结果，会保留每群页码、排序方式、文件名关键词、内容、勾选和文件夹草稿、折叠状态及滚动位置，同时保留时间选择、未保存的搜索、账号列表和未保存的配置。点击“保存配置”成功后，会清空群搜索和整个文件预览及相关草稿，并收起设置框；已选群和时间范围保留。再次读取时各群从第 1 页展示新结果。

重新读取产生新的预览时，各群重新展示新结果，排序回到从晚到早，查询内容清空、保存状态筛选回到“默认筛选”设置的初始状态，分组筛选也回到全部；确认保存后展示本次保存结果，各群沿用保存前的保存状态筛选，不会统一切到「全部」，没有可沿用记录的群按「默认筛选」设置；各群的展开／收起状态同样保持不变。分页失败时可“重试加载本页”，这只读取已有结果，不重新采集或复制文件。

这些界面草稿只在当前 DSH 窗口运行期间保留，退出后未提交的勾选、目录修改和配置草稿不保留。后端已生成的预览与上次结果在未点击“保存配置”清空前可于重启后查看并再次检查、确认保存；不会自动执行。需要长期保留群和保存根目录，仍应点击“保存配置”，随后重新读取文件。

## 怎样把不同文件放到同一文件夹

系统默认使用完整文件名去掉最后一个扩展名作为文件夹。例如 `OOLU2174232310电放.pdf` 与同名的 `.docx` 会进入同一个 `OOLU2174232310电放` 文件夹。

如果“补充说明.pdf”也属于这票资料，可以在同一群中补选它，将该行的“文件保存目录”改为 `OOLU2174232310电放`。需要让本群已选资料统一归入某个目录时，点「设置默认目录」填写目录名；需要把当前这批选中文件固定成一组时，点「为选中文件创建目录」创建一个同名目录的分组。保存目录优先级为逐文件修改 > 分组 > 默认目录 > 系统分配目录；移除分组或点群名旁默认目录路径后的“×”只撤销对应分配，保留已有的逐行调整。

只填写最后一层目录名。每份文件仍在原来的“群／文件接收日期”下，不能把它改到另一个群、另一天，或输入 `D:\其他目录`、`..` 等路径。跨日期选中的文件即使填写同一个目录名，也分别位于各自文件接收日期目录中。所有目录调整都要经过最后的“确认并保存”才落盘；没有确认时不会移动既有归档。

## 什么样的文件会保存

“读取全部文件”不限制文件名和格式，默认勾选可保存且尚未保存的附件。“读取提单文件”用下列文件名规则与格式白名单生成默认勾选；白名单内的普通文件可以人工补选。无论哪种模式，都要经过二次确认才会保存。

文件名初筛规则如下，不调用大模型，也不检查承运人系统：

- 数字编号至少 6 位；或字母数字组合总长至少 8 位、含至少 4 位数字。
- 可包含短横线或下划线连接，候选编号最长 32 位。
- 全角字母数字会先统一处理；识别提单号时不包含扩展名，格式另行筛选。
- 明显的纯日期、日期时间编号不作为提单号。

提单模式的格式白名单只包含 `pdf、png、jpeg、jpg、svg、doc、docx、pptx、zip、xls、xlsx`，大小写均可，例如 `.PDF`、`.JpEg`、`.XLSX`、`.JPG`。以最终扩展名为准：`提单123456789.pdf.exe` 不通过，`.txt`、`.ppt` 等不在当前白名单，在提单模式中不能勾选；需要这些附件时改用“读取全部文件”。ZIP 作为整份附件保存，预览阶段不解压筛选内部文件；保存后可直接解压（见“保存目录和结果”）。RAR 不在提单白名单内，需改用“读取全部文件”整包保存，保存后同样可直接解压。本规则按扩展名判断，不检测文件内容类型。

| 文件名 | 读取提单文件后的默认状态 | 读取全部文件后的默认状态 |
| --- | --- | --- |
| `提单123456789.pdf` | 默认勾选，命中 `123456789` | 默认勾选 |
| `177WBTBTN11759A正本.pdf` | 默认勾选 | 默认勾选 |
| `MAEU-1234-567890.zip` | 默认勾选 | 默认勾选 |
| `提单123456789.txt` | 格式不在范围，不可选 | 默认勾选 |
| `提单123456789.xlsx` | 默认勾选，命中 `123456789` | 默认勾选 |
| `提单987654321.xls` | 默认勾选 | 默认勾选 |
| `提单123456789.jpg` | 默认勾选，命中 `123456789` | 默认勾选 |
| `费用明细2026.xlsx` | 无长编号不命中，可人工补选 | 默认勾选 |
| `会议纪要.pdf` | 未默认勾选，可人工补选 | 默认勾选 |
| `20261028会议安排.pdf` | 纯日期不命中，可人工补选 | 默认勾选 |
| `第3个50万美金对应的提单号.zip` | 无实际长编号，可人工补选 | 默认勾选 |

表中的可选状态还要求来源和校验信息可靠。其他合同号、订单号也可能具备相同命名特征，因此默认勾选是一轮初筛，不保证每个命中编号都是真实提单号；人工需核对并作最终选择。两种方式在真正保存时，都要求本机存在原件或可复用的可靠归档副本，并通过内容校验。

## 保存目录和结果

系统默认建议 `根目录\群名称\文件接收日期（YYYY-MM-DD）\文件名（去扩展名）\文件`，界面提示使用 Windows 的反斜线 `\`。手工修改只替换其中“文件名（去扩展名）”这一层；群和文件接收日期保持原样。设置自定群子目录后，使用该中文名称，不给群目录添加自动英文标识。例如：

```text
D:\filetest\测试沟通群\2026-10-29\
├─ OOLU2174232310电放\
│  ├─ OOLU2174232310电放.pdf
│  └─ OOLU2174232310电放.docx
└─ 提单987654321\
   └─ 提单987654321.zip
```

“待人工确认”表示可保存但尚未执行；“未选择，仅列出”表示本次不保存。“已保存”表示副本通过校验；“已存在”表示已有相同内容，可以复用。本地缺失、来源冲突、缺少校验信息或复制失败需要核对处理。保存后仍可补选或重试，再次经过确认框提交，重试只提交重新勾选的文件；不重新复制校验一致的同位置副本。

文件夹按完整文件名去掉最后一个扩展名命名。同名的 `.pdf` 与 `.docx` 共用文件夹，“正本”和“电放”等不同文件名分别建文件夹。同名但内容不同的文件在同一文件夹内保留版本；ZIP/RAR 仍保存整包，默认不自动解压，保存后可直接解压（主包内容拍平到所在目录，子压缩包内容解压到以它命名的子目录），也可在「群与保存目录」的「压缩包处理」中开启保存后自动解压与逐层处理子压缩包。

zip/rar 保存后想要包内文件时，点文件列表「状态」列的「解压」（已保存的 zip/rar 行才显示，旁边给出「已解压 N 份文件」），或在「按目录查看已保存文件」中点压缩包文件卡片上的「解压」；后者也能处理以前保存的包。点击「解压」不再弹框，直接把包内所有受支持的条目拍平解压到压缩包所在目录（`日期\压缩包名\`，不保留包内自带的子目录结构）；子压缩包（递归或手动解压已落地的子包）的内容解压到以它名字（去扩展名）命名的子目录，逐层递归形成 `日期\压缩包名\子包名\…`，整包始终保留作为来源。加密、不支持的压缩方式、超过单份大小限制（2 GiB）或包内重名的条目会自动跳过；本次解压总量超过 8 GiB 时整包拒绝；落地路径超长的条目计入「路径过长」。每份文件解压时校验 CRC32 和解压后大小，同名同内容复用为「已存在」，同名不同内容按版本后缀另存为「新增」。解压进行中按钮变为「停止解压」，可点它取消（取消在文件之间生效，rar 单份解压时同步执行）。完成后浮出「解压完成」提示，按 新增／已存在／失败／跳过／路径过长 计数。

「群与保存目录」设置里有「压缩包处理」两项开关：「保存后自动解压」（默认关）与「同时处理子压缩包」（默认关）。开启自动解压后，批量保存、单行保存与「保存到已存在目录」三条保存路径完成后，会自动解压本次保存的压缩包，结果浮出「自动解压」提示；解压失败不影响保存结果。开启「同时处理子压缩包」后，解压落地的 zip/rar 会被逐层递归解压，最多 8 层，每层内容放进以该子包命名的子目录（逐层嵌套，不会平铺进主目录）；关闭时包内压缩包只原样落地为普通文件，想再解就对着落地后的文件单独点一次「解压」，同样放进以其命名的子目录。手动点「解压」时是否递归，按当前「同时处理子压缩包」设置决定。

解压出的文件记入已保存索引（`kind: extracted`，含来源压缩包与包内路径）。主包内容拍平在压缩包所在目录、子包内容在以其命名的子目录，它们都会在「按目录查看已保存文件」中与归档文件一起直接列出（子包产物在其命名子目录下），文件名旁标注「来自 xxx.zip/rar」，时间沿用压缩包的消息时间，可以重命名或删除，删除解压产物不影响整包。zip 支持 ZIP64 与 UTF-8/GBK 文件名；rar 由内置官方 unrar WASM 解压，头加密、分卷、损坏的包会明确报错，不提供密码输入，包内加密条目跳过，7z 等仍只整包保存。

文件名称中的非法字符会替换为下划线。过长名称会在必要时缩短并附加稳定摘要，扩展名保留；如果保存根目录或群目录太长，仍无法安全保存，会显示“保存路径过长”，请缩短这两个目录后重试。目标文件夹名称被其他文件占用时，显示目录冲突，请先核对归档。

升级前直接放在日期目录中的文件，只有在本次被勾选并人工确认后，才校验、归入新子目录并显示“已存在”；新位置副本校验通过后才移除匹配的旧位置文件。读取预览不做这一步。内容不同或未选中的旧文件保留。若希望统一整理普通文件，选择“读取全部文件”和对应时间范围，检查选择后确认。可复用可靠旧副本时，无需为了迁入而重新下载一份原件。

插件不移动企微原件，不覆盖内容不同的同名文件。两种方式之间切换不会删除之前保存的文件，切回提单方式后普通文件仍会保留。改变中文子目录名也不会自动搬走先前纯群名目录中的文件。

## 按归档目录建单

归档只是把文件放好。建单是把一个归档目录里的单据（一票）识别成订单，导出 Excel 给后续录单用。

**粒度：一个目录 = 一票。** 目录里的 PDF、Word、Excel、图片会递归读取，文件名不参与归票；同一目录内不同提单号也会按提单号各成一票。

- 面板：在「AI 建单」区点「重新建单」，或点「选择其他目录建单」挑一个归档目录。列表显示最近归档的目录、当前状态与进度、完整度、缺失必填和校验提示；完成后给出 Excel 路径。
- 对话：让模型调用 `wecom_atom_order { action: "build", directory: "D:\\客户资料\\..." }`，再用 `status` 看进度。
- 归档后自动：先勾选「归档完成后自动建单」，之后每次确认归档成功，插件会对本次实际落盘的目录排队建单。默认关闭。

输出固定写到该目录下的 `_orders`，文件名 `订单_<目录名>_<时间>.xlsx`，不会移动或删除原件。目录内单据超过 200 份会拒绝建单，通常是目录不属于一票。

扫描件和图片会渲染成页面图片交给当前默认模型识别，所以默认模型需要支持图片；纯图片又读不到文字时，结果会带提示，请人工核对。中文 PDF 的文字层靠随包 CMap 解析。模型没跑通、目录不可读或文件仍在变化时，任务会显示失败原因，可点「重新建单」重试；文件没有变化时再次建单会自动跳过。

## 使用边界

列表范围受本机已同步消息和附件记录限制，不能保证企微服务端全量历史。来源读取失败会显示错误，不能当作“当天没有文件”。当前本机适配已在企微 5.0.12.6026 验证，其他版本需另行验证。

文件、图片、视频的本机原件分别从企微账号目录的 `Cache/File`、`Cache/Image`、`Cache/Video` 缓存区按大小与内容校验匹配；已下载的图片（jpg、png 等）可正常归档，未在本机缓存的文件仍需先在企微打开或下载。

文件清单与保存结果用于业务员人工核对资料，文件数量不等于业务单量，也不能证明物流订单已经处理。
