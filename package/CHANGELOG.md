# Changelog

## 未发布

- 识别链路与原始实现 `ai-order-builder-v2` 对齐并锁定基线：新增 `test/recognition-baseline.test.mjs`，校验提示词模板 SHA-256、29 字段契约（key/名称/段落顺序/必填）以及订单与台账两种模式的提示词结构。
- `pipeline.mjs` 不再各自维护 `FIELD_TO_STD` / `AI_FIELDS` / `NULLABLE_FIELDS` / `REQUIRED_FIELDS`，全部由 `dictionary.mjs` 派生，避免字段清单两处漂移。
- 删除 `validate.mjs` 中重复的 `transship_country` 键（后一个校验器本来就会覆盖前一个，行为不变，构建警告消除）。
- 修复 Excel 附件读取：原 `import('xlsx')` 依赖未随包，`.xlsx/.xls` 实际解析失败；现统一用已随包的 exceljs 读取 `.xlsx`，旧版 `.xls` 返回「另存为 .xlsx」提示。
- 台账识别接入与订单共用的后处理：值清洗、单位/币制/国家归一化，以及提单号、目的地、通知人、付款方式、海运费币制等规则兜底，在用户选中的列内生效；`extraction/` 与入库值都体现推导结果。
- 台账入库从客户端轮询后转发改为 Host 在识别完成时直接执行：任务上记录 `ingest`（rev/票数/格数），入库失败只标记任务、不回滚识别结果；页面中途关闭或轮询超时不再留下「已识别未入账」的中间态。
- `ledger-ingest` 保留为幂等补写入口：重复入库同一份结果不升 rev、不追加审计；识别完成后客户端直接消费 Host 的入库结果。
- 识别入口移到文件整理页的「已保存目录」视图：选中目录就是识别对象，目录头原来「复制文件目录 + 路径」一行改为 AI 识别工作区，保留小图标复制路径；工作区显示排队/识别步骤与进度、可取消，完成后给出「已写入台账：本票 M 格 · 台账共 N 票」；失败给出原因，再点一次即重试。
- 未创建台账时目录头提示「尚未创建台账」，点「去创建」切到台账页并直接打开新建台账弹窗。
- 台账页移除归档目录下拉与识别按钮，只保留查看、复核与导出；「字段设置」并入信息行。切回台账页时按 revision 刷新，看到目录页识别的入库结果。
- 离开目录或切页不丢任务：回到同一目录会接上仍在识别的任务，结束后补写一次未入库的结果并显示票数/格数。
- 修复识别工作区一直停在「排队中 · 0%」：识别任务在入库前 `mode` 仍是默认的 `order`，客户端按 `mode=ledger` 过滤导致整段识别都匹配不到任务；现改为按目录认领任务，完成时再区分模式，同目录在跑建单任务时提示「目录正在建单，本次未识别」。
- 看板支持下钻到台账：点击图上的柱、点或扇区会切到台账页，并按该标签（有拆分时同时按系列）筛选；月份维度按「入账时间」前缀展开，空值按未填写筛选。台账提示行显示「看板筛选：条件 · 显示 N 票」，可一键清除；手动在表格里清除筛选也会同步收起提示。
- 下钻首版只筛已载入的热数据（1000 行），归档分片不参与；存在归档或未载入行时会提示这一边界。刷新重建工作簿后会自动重新装配当前筛选。
- 测试 128 项。

## 0.8.0

日期：2026-11-13

- 看板拆成「图库」与「展示中」两层：保存图表只写入图库，不直接上板；图库里的每张图可逐张「展示 / 隐藏」，看板只渲染标为展示中的图。
- 点「图库」查看全部定义（按更新时间倒序），可展示、隐藏、编辑或删除；新建保存后自动打开图库并提示「已保存到图库」。
- 上限：图库最多 60 张，看板最多展示 24 张；超过展示上限时提示「看板最多展示 24 张图」，图仍留在图库。
- 旧版 `ledger-dashboards.json` 中没有展示标记的图按「展示中」读取，升级后看板保持原样；新保存的图默认只入库。
- Host 新增 `ledger-dashboard-pin { id, pinned }`；`ledger-dashboard` 仍只聚合展示中的图，另返回图库定义列表与展示数，隐藏的图不参与取数。
- 测试 118 项。

## 0.7.0

日期：2026-11-13

- 看板重构为「按台账字段自己拼图」：图表不再写死，从台账当前字段目录取维度、拆分系列与数值字段，可随时新建、编辑、删除，最多 24 张。
- 八种图表：柱状图、条形图、折线图、面积图、饼图、环形图、明细表、指标卡；分类图支持 topN + 「其他」、按值或按标签排序，柱/条/线/面支持拆分系列（最多 6 条 + 「其他」）与分组/堆叠，月份维度可选 3/6/12/24 个月或全部。
- 指标为票数 / 合计 / 平均；合计与平均只能选台账里的数字字段，拆分只能选分类字段，保存前按当前台账字段校验，字段被删后旧图显示失败原因而不是整页报错。
- 设计器带实时预览（260ms 防抖，不落盘）；每张图可选单栏或通栏。明细表用 TanStack Table 渲染所选列与前 N 行，指标卡显示单个聚合值。
- 图形定义单独存 `<状态目录>/ledger-dashboards.json`，与 `ledger.json` 分开写；首次打开给三张默认图（月度趋势、核对状态、来源群票数），只有保存或删除才落盘。删改看板不影响台账数据。
- 客户端改用 TanStack Charts 1.5 渲染柱/条/线/面/饼/环，TanStack Table 9 渲染明细表；Host 仍只返回聚合结果与表格前 N 行，不返回全量台账行。
- 「全部 / 某月」范围与 15 秒版本轮询保留，版本号纳入看板定义文件的 mtime/大小，改图后其他窗口也会自动刷新。
- 测试 115 项。

## 0.6.0

日期：2026-11-13

- 台账改为「热窗 + 月度归档」：打开台账时把超过 30 天、或热窗超过 2000 行的旧票移入 `ledger-archive/YYYY-MM.json`，索引写在 `ledger-archive.json`；热窗只保留近期票，页面数据量不再随台账总票数增长。
- 归档先写分片与索引、再从 `ledger.json` 删行；中途失败时热窗保持原样，重跑幂等。识别入库后也会自动归档一次。
- 新增「看板」页签：直接按台账数据出图，可切换「全部 / 某月」范围；顶部为票数、平均完整度、已归档、待处理四张 KPI，下面依次是近 12 个月入账趋势、识别状态环图、完整度分布与最多 4 个分类字段的取值分布。
- 看板只向客户端返回聚合结果，不返回明细行；每 15 秒比对一次轻量版本号（只 stat 台账与归档索引），归档或复核变化后自动重新聚合。
- 台账信息行显示已归档票数；「导出 Excel」改为读取热窗 + 全部归档分片，归档票也会进入导出。
- 测试 106 项。

## 0.5.1

日期：2026-11-12

- 台账页从固定六列改为按台账配置投影：首次进入显示「创建台账」，勾选内置识别字段（29 个）或添加自定义字段（最多 10 个），字段定义同时驱动后续识别。
- 识别到台账：选择归档目录后按台账字段识别，写 `extraction/<run>.json` 与 `ledger.json`；表格显示完整度、核对状态与识别值。
- 人工复核直接改单元格，写入 `review.json` 审计；「还原人工修改」撤销；复核值优先于识别值，再次识别不覆盖。
- 重识别不覆盖复核显示值；已复核格收到不同识别值时标黄并提示「有新识别值」，人工保存后清除。
- 台账字段设置可再次打开修改：改字段集合只重算视图，不重新识别；旧票显示「待重识别」，重新识别后恢复。
- 隐藏列、删除字段只影响显示，已识别值与复核值仍保留在 `ledger.json`；恢复列/字段即可找回。
- 新建台账的列顺序：票 ID（冻结）、完整度、核对状态、用户选择的识别字段，最后追加归档目录/来源群/归档日期/入账时间/文件数；已有台账不改动，重新保存「字段设置」后按新顺序生成；上一版误改过列序的台账在首次读取时一次性还原（含列宽、活动格）。
- 台账新增「导出 Excel」：导出前可逐列勾选，默认不导出票 ID 与归档信息；勾选结果记入台账配置，导出文件在状态目录的 `exports` 下。
- 台账的名称、导出 Excel、还原人工修改与票数等信息行，以及归档目录选择、「识别到台账」「字段设置」，都移到表格卡片外（与文件整理的动作行同排同间距）；卡片内只保留表格。
- 旧版 `ledger-local.json` 的单元格修改在首次建台账时迁移为复核值，原文件改名备份。
- 内置 29 个字段生成的提示词与 0.5.0 逐字一致；测试 92 项。

- 客户端改为在 0.4.0 发布版 bundle 上注入建单面板：0.4.0 的 `client.js.map` 已过期（与 0.8.5 界面不符），不再据此全量重建，解压/目录视图/分组等界面保持原样。
- 测试 26 项：新增客户端注入与 bundle 装载测试；建单流水线用替身模型跑通文本 + 扫描 PDF 的端到端。

## 0.4.0

日期：2026-11-10

- 新增 `wecom_atom_preview`：`start` 生成预览（bill/all、日期范围默认今天）、`cancel` 取消、`plan` 估算归档与自动命名目录、`confirm` 按预览勾选批量归档。
- `confirm` 必须显式给 `groupIds`，自动命名目录需 `allowAutoFolders: true`；支持 `groupSelections` / `groupFolders` / `changes` 逐群、逐文件调整。
- 新增 `wecom_atom_settings`：`save` 合并保存配置（省略字段沿用当前值，`groups` 传完整列表），`clear` 清空当前预览/结果；有任务时保存需 `confirm: true`。
- `start` / `confirm` 立即返回 `running`，进度通过 `state` / `records` 轮询，与面板一致。
- 工具测试扩到 24 项，参数 schema 用真实 `defineTool` 编译校验。

## 0.1.0

日期：2026-11-10

新插件：把 `dsh-wecom-fws` 的能力暴露为对话内工具，面板与对话共享同一个 Workbench。

- 新增 `wecom_fws_query`：`state` / `accounts` / `groups` / `records` / `directories` / `saved-folders`。
- 新增 `wecom_fws_file`：`save` / `extract` / `rename` / `delete`，只做单份操作。
- `jobId` 省略时取当前预览任务；`save` 省略 `groupName` 时按群归档目录推导。
- 结果裁剪掉面板用的完整 snapshot，仅返回任务头、群摘要或本次操作结果。
- 不提供批量 `start`/`confirm`/`save`：授权动作仍由用户在面板完成。
- 最终一致：工具与面板同源，面板下次读取时同步；无实时推送。
